# 知识库使用说明

## 简介

此文件夹用于存放知识库的 Markdown 文档。所有 `.md` 文件将自动出现在左侧菜单的"知识库"菜单下。

## 使用方法

### 添加新文档

1. **添加文档**: 直接将 `.md` 文件放入 `public/KnowledgeBase/` 文件夹即可
2. **更新文件列表**: 在 `files.json` 中添加新文件的文件名（包含 `.md` 扩展名）
   ```json
   {
     "files": [
       "README.md",
       "示例文档.md",
       "你的新文档.md"
     ]
   }
   ```
3. **刷新页面**: 刷新浏览器页面，新文档会自动出现在菜单中

### 查看文档

- 点击左侧菜单"知识库"下的文档名称即可查看内容
- 文档会使用 `marked` 库自动解析为 HTML 并显示

## 文件命名建议

- 使用有意义的文件名，例如：`Vue3基础教程.md`、`JavaScript高级特性.md`
- 避免使用特殊字符和空格，建议使用 `-` 或 `_` 连接
- 文件名会直接显示在菜单中，请保持简洁明了
- 支持中英文文件名

## 技术说明

### 文件列表配置

系统通过读取 `files.json` 文件来获取文档列表。每次添加新文档后，需要：
1. 在 `files.json` 的 `files` 数组中添加文件名
2. 刷新页面以加载新的菜单项

### Markdown 支持

- 支持标准 Markdown 语法
- 支持 GitHub 风格的 Markdown (GFM)
- 支持代码高亮
- 支持表格、列表、链接、图片等常见元素

### 示例文档

可以查看同目录下的 `示例文档.md` 了解格式要求和语法示例。

## 注意事项

- ⚠️ **重要**: 添加新文档后，务必在 `files.json` 中添加文件名，否则文档不会出现在菜单中
- 仅支持 `.md` 格式的文件
- `README.md` 和 `files.json` 不会被显示在菜单中
- 文档使用 UTF-8 编码
- 建议文档文件大小控制在 1MB 以内，以确保加载速度

## 文件结构

```
public/KnowledgeBase/
├── README.md              # 使用说明（不显示在菜单）
├── files.json             # 文件列表配置（不显示在菜单）
├── 示例文档.md            # 示例文档
└── 你的文档.md            # 你的文档...
```
