## 项目概述

### 项目简介

浩南知识库是一个基于 Vue 3 构建的现代化知识管理系统前端应用，旨在提供一个美观、高效、易用的知识管理平台。项目集成了 Element Plus UI 组件库，提供了完整的组件演示系统、文档管理系统、以及丰富的交互功能。

### 主要特性

- 🎨 **现代化UI设计**: 基于 Element Plus，提供美观统一的界面风格
- 🔐 **用户认证系统**: 完整的登录/登出功能，支持本地存储
- 📱 **响应式设计**: 完美适配桌面端和移动端
- 🌳 **无限层级菜单**: 递归组件实现的动态菜单系统
- 📑 **标签页导航**: 支持多标签页管理和拖拽排序
- 🔍 **智能搜索**: 全局页面搜索功能，支持模糊匹配和高亮显示
- 📚 **知识库管理**: Markdown 文档自动解析和展示
- 🎯 **组件演示**: 完整的 Element Plus 组件使用演示
- 📝 **开发记录**: 时间线形式展示项目开发历史

### 项目定位

- **个人知识管理平台**: 用于管理和展示个人技术文档和知识
- **组件库演示系统**: 完整的 Element Plus 组件使用示例
- **Vue 3 学习项目**: 展示了 Vue 3 Composition API、Pinia、Vue Router 等现代前端技术的最佳实践

## 核心功能详解

### 1. 用户认证系统

#### 功能描述

完整的用户登录/登出功能，支持"记住我"功能，登录状态持久化到本地存储。

#### 技术实现

**文件位置**: `src/store/userStore.js`

```javascript
// 核心功能
- login()           // 用户登录
- logout()          // 用户登出
- saveToStorage()   // 保存登录状态
- loadFromStorage() // 恢复登录状态
- extendLoginTime() // 延长登录时间
```

**登录逻辑**:
1. 用户在 `Login.vue` 页面输入用户名和密码
2. 验证通过后调用 `userStore.login()`
3. 根据"记住我"选择，保存到 `localStorage` 或 `sessionStorage`
4. 更新登录状态，路由跳转到仪表板

**状态持久化**:
- 支持 `localStorage`（记住我）和 `sessionStorage`（临时登录）
- 自动恢复登录状态，刷新页面不丢失

### 2. 无限层级递归菜单

#### 功能描述

支持无限层级嵌套的侧边栏菜单系统，菜单项可以动态添加、删除、更新和排序。

#### 技术实现

**文件位置**: 
- `src/store/menuStore.js` - 菜单状态管理
- `src/components/RecursiveMenu.vue` - 递归菜单组件

**核心特性**:
```javascript
// 菜单项数据结构
{
  index: 'unique-id',        // 唯一标识
  title: '菜单名称',          // 显示名称
  icon: 'IconName',           // Element Plus 图标名称
  path: '/route/path',        // 路由路径
  sort: 1,                    // 排序值（数值越小越靠前）
  children: []                // 子菜单数组（支持无限嵌套）
}
```

**递归实现**:
```vue
<!-- RecursiveMenu.vue 核心逻辑 -->
<RecursiveMenu 
  :items="item.children" 
  :level="level + 1" 
/>
```

**动态侧边栏宽度**:
- 根据展开菜单的层级自动调整侧边栏宽度
- 基础宽度 250px，每增加一级展开层级额外增加 30px
- 最大宽度限制 600px

### 3. 标签页导航系统

#### 功能描述

类似浏览器的多标签页功能，支持标签页打开、关闭、切换、拖拽排序。

#### 技术实现

**文件位置**: `src/components/TabsNavigation.vue`

**核心功能**:
- ✅ 标签页打开（点击菜单项自动打开）
- ✅ 标签页关闭（点击关闭按钮或右键菜单）
- ✅ 标签页切换（点击标签页切换路由）
- ✅ 拖拽排序（使用 `sortablejs` 库）
- ✅ 右键菜单（关闭当前、关闭其他、关闭全部）

**标签页数据结构**:
```javascript
{
  id: 'unique-id',      // 标签页唯一标识
  title: '页面标题',     // 显示标题
  path: '/route/path',   // 路由路径
  icon: 'IconName'      // 图标名称
}
```

### 4. 全局智能搜索

#### 功能描述

顶部导航栏的全局搜索功能，支持页面名称、路径、分类等多维度搜索。

#### 技术实现

**文件位置**: `src/App.vue` (搜索相关逻辑)

**搜索算法**:
```javascript
// 多维度评分系统
- 标题完全匹配: 100分
- 标题开头匹配: 80分
- 标题包含匹配: 60分
- 关键词匹配: 50分
- 路径匹配: 40分
- 分类匹配: 30分
```

**搜索特性**:
- 实时搜索建议（输入时显示建议列表）
- 文本高亮显示（匹配关键词高亮）
- 回车键快速跳转
- 支持模糊搜索

### 5. 知识库系统

#### 功能描述

基于 Markdown 的文档管理系统，自动解析和展示 Markdown 文档。

#### 技术实现

**文件位置**:
- `src/utils/knowledgeBase.js` - 工具函数
- `src/views/KnowledgeBase/KnowledgeBase.vue` - 文档视图组件

**工作流程**:
1. 从 `public/KnowledgeBase/files.json` 读取文件列表
2. 动态生成菜单项添加到"知识库"菜单下
3. 用户点击文档，路由跳转到 `/knowledge-base/:filename`
4. 加载对应 Markdown 文件
5. 使用 `marked` 库解析为 HTML
6. 应用样式渲染显示

**特性**:
- 支持标准 Markdown 和 GFM 扩展
- 自动处理开发/生产环境的路径差异
- 错误处理和友好提示

### 6. Element Plus 组件演示

#### 功能描述

完整的 Element Plus 组件使用演示，每个组件都有独立的演示页面。

#### 实现方式

- 每个页面包含：组件演示、属性说明、代码示例
- 统一的页面结构和交互方式
- 支持属性动态配置和实时预览

### 7. 个人技术文档系统

分类展示个人技术文档的系统，支持多个文档分类。

#### 功能特点

- 卡片式布局展示
- 每个分类独立页面
- 预留文档数据接口

### 8. Canvas 画布功能

#### 功能描述

基于 HTML5 Canvas 的签名/画图功能演示。

#### 核心功能

- 鼠标和触控设备支持
- 线条粗细调节
- 颜色选择
- 签名保存和清除
- 平滑绘制算法

### 9. 开发记录系统

#### 功能描述

时间线形式展示项目开发历史记录。

#### 数据存储

- 存储在 `src/data/messageStore.js`
- 支持多种消息类型：primary、success、info、warning、danger
- 包含标题、内容、标签、分类等信息

## 状态管理

### Pinia Store 设计

项目使用 Pinia 作为状态管理库，采用 Composition API 风格。

### menuStore - 菜单状态管理

#### 状态定义

```javascript
const isCollapse = ref(false)           // 侧边栏折叠状态
const menuItems = ref([...])            // 菜单项数据（树形结构）
const activeMenu = computed(...)        // 当前激活的菜单项
```

#### 核心方法

```javascript
- toggleCollapse()              // 切换折叠状态
- handleMenuSelect(index)       // 处理菜单选择
- addMenuItem(parentIndex, item) // 添加菜单项
- updateMenuItem(index, updates) // 更新菜单项
- removeMenuItem(index)          // 删除菜单项
- sortMenuItems(items)           // 菜单排序
- loadKnowledgeBaseFiles()       // 动态加载知识库文件
- generateBreadcrumb(path)      // 生成面包屑
```

### userStore - 用户状态管理

#### 状态定义

```javascript
const userInfo = ref({...})      // 用户信息
const isLoggedIn = ref(false)    // 登录状态
const loginTimestamp = ref(0)     // 登录时间戳
const rememberLogin = ref(false)  // 是否记住登录
```

#### 核心方法

```javascript
- login(userInfo)                // 用户登录
- logout()                       // 用户登出
- saveToStorage()                // 保存到本地存储
- loadFromStorage()              // 从本地存储加载
- extendLoginTime()              // 延长登录时间
```

### 数据持久化

- **用户信息**: 存储在 `localStorage` 或 `sessionStorage`
- **菜单配置**: 目前为静态数据，可扩展为持久化存储

## 常见问题

### Q1: 如何添加新的菜单项？

**A**: 在 `src/store/menuStore.js` 的 `menuItems` 数组中添加新项，或在"菜单管理"页面添加。

### Q2: 路由跳转后页面不更新？

**A**: 检查路由配置是否正确，确保组件正确导入。

### Q3: 样式不生效？

**A**: 
- 检查是否使用了 `scoped` 样式（可能需要使用 `:deep()`）
- 检查样式优先级
- 检查 PostCSS 配置

### Q4: 构建后资源路径错误？

**A**: 检查 `vite.config.js` 中的 `base` 配置是否与实际部署路径匹配。

### Q5: 移动端显示不正常？

**A**: 
- 检查响应式样式
- 检查 viewport 配置
- 检查 rem 适配配置
